# Daily 미션 카탈로그

## 난이도별 포인트

| 난이도 |   포인트 |
| ------ | -------: |
| 쉬움   | 10 Point |
| 보통   | 20 Point |
| 어려움 | 30 Point |
| 특별   | 50 Point |

포인트는 개별 미션에서 임의로 정하지 않고 난이도 정책을 따른다.

## 등록된 미션

### 그림자를 따라

- 설명: 오늘 가장 재미있는 그림자를 찾아 사진을 남겨보세요.
- 유형: 관찰
- 난이도: 보통
- 예상 시간: 10분
- 인증 방식: 사진 1장
- 포인트: 20 Point
- 유사 미션 그룹: `SHADOW_OBSERVATION`

### 쉼표

- 설명: 마음에 드는 장소를 발견했다면 10분 동안 머물러 보세요.
- 유형: 휴식
- 난이도: 쉬움
- 예상 시간: 10분
- 인증 방식: GPS 10분 체류
- 포인트: 10 Point
- 허용 이동 범위: 기준점에서 50m
- 유사 미션 그룹: `REST_STAY`

### 같은 색 세 장면

- 설명: 산책 중 같은 색을 가진 서로 다른 대상 세 가지를 발견해보세요. 같은 물건을 반복 촬영하면 인정되지 않아요.
- 유형: 관찰·수집
- 난이도: 보통
- 예상 시간: 10~20분
- 목표 수치: 서로 다른 대상 3개
- 인증 방식: 사진 3장
- 포인트: 20 Point
- 날씨·시간대 제한: 없음
- 유사 미션 그룹: `COLOR_COLLECTION`

### 신호등 찾기

- 설명: 신호등이 있는 교차로를 찾아 사진으로 남겨보세요.
- 유형: 탐색
- 난이도: 쉬움
- 예상 시간: 3분
- 인증 방식: 사진 1장
- 포인트: 10 Point
- 유사 미션 그룹: `ROAD_FACILITY`
