## 1차 미션 제작 우선순위

1. `공산성연지`, `제민천`, `공주 중동성당`, `공주향교`, `금학생태공원`을 핵심 장소로 선정한다.
2. 각 장소마다 GPS 방문 미션 하나만 만들지 않고 사진·퀴즈·체류·걷기를 섞는다.
3. 공산성 일대의 장소들은 서로 가까우므로 같은 빙고판에 과도하게 몰리지 않도록 동일 유사 그룹으로 묶는다.
4. 정확한 정답이 없는 풍경 사진은 AI 자동 반려 대신 관리자 검수 요청이 가능한 주관형 사진 미션으로 만든다.
5. 운영 공개 전 현장 접근성, 운영 시간, 촬영 제한, GPS 좌표를 한 번 더 확인한다.

## 권장 미션 풀 구성

- 장소 방문(GPS): 8개
- 사진 인증: 6개
- 퀴즈: 4개
- GPS 체류·걷기: 4개
- 텍스트 기록·직접 완료: 3개 이상

최소 25개만 맞추기보다 무작위 개인화에 필요한 여유를 위해 30~35개의 활성 미션을 먼저 준비하는 편이 좋다.
